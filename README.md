# Three-Way Sync (Python / Go / Java)

Python を書くと、Go と Java のコードが横に並んで生成される VS Code 拡張機能です。
カーソルを動かすと、同じ概念にあたる行が3画面で同時にハイライトされます。
「Python と Go の構造が分かれば Java が分かる」を、見て体験するための学習支援ツールです。

## インストール

1. このページ右側の「Releases」から最新版を開き、「Assets」にある `three-way-sync-x.x.x.vsix` をクリックして保存します。
2. VS Code の左端にある拡張機能アイコン（四角が4つ）をクリックします。
3. パネル右上の「…」→「VSIXからのインストール…」を選び、保存したファイルを指定します。

## 使い方

1. 作業用のフォルダを開きます（「ファイル → フォルダーを開く」）。
2. `Ctrl+Shift+P` を押し、`Sync` と入力して「Three-Way Sync: 開始（3分割で開く）」を実行します。
3. 左の `main.py` を編集して `Ctrl+S` で保存します（または `Ctrl+Alt+Y`）。
4. 中央に Go、右に Java が生成されます。
5. どれかの画面でカーソルを動かすと、対応する行が他の2画面でも光ります。マウスを載せると解説が出ます。

## 使うAIを選ぶ

画面右下のステータスバーにある「3言語同期: …」をクリックすると切り替えられます。

| 選択肢 | 内容 |
| --- | --- |
| モック | APIを呼ばず、固定のサンプルを返します。無料。動作確認用。 |
| Anthropic (Claude) | 書いた Python を実際に変換します。ご自身のAPIキーが必要。 |
| OpenAI | 同上。ご自身のAPIキーが必要。 |

- APIキーは各自で用意してください。キーは設定ファイルではなく、OSの資格情報保管庫に保存されます。
- 本物のAIを選ぶと、変換のたびにAPI料金がかかります。保存時の自動変換を止めるには、設定 `threeWaySync.convertOnSave` をオフにします。

## 知っておくとよい点

- 生成後に Go / Java / Python を手で編集すると、行の対応がずれるためハイライトは止まります。もう一度変換すると戻ります。
- VS Code を再起動した直後もハイライトは出ません。`main.py` を一度保存してください。
