# Three-Way Sync (Python / Go / Java)

Python / Go / Java のどれか1つを書くと、残り2言語のコードが横に並んで生成される VS Code 拡張機能です。
カーソルを動かすと、同じ概念にあたる行が3画面で同時にハイライトされます。
「Python と Go の構造が分かれば Java が分かる」を、見て体験するための学習支援ツールです。

## インストール

1. このページ右側の「Releases」から最新版を開き、「Assets」にある `three-way-sync-x.x.x.vsix` をクリックして保存します。
2. VS Code の左端にある拡張機能アイコン（四角が4つ）をクリックします。
3. パネル右上の「…」→「VSIXからのインストール…」を選び、保存したファイルを指定します。

## 使い方

1. 自分で書いている Python / Go / Java のファイルを開きます（これが「起点」になります）。
2. エディタ右上の3分割ボタン（または右クリック →「Three-Way Sync: このファイルで3分割を開始」）を押します。
   - `Ctrl+Shift+P` →「Sync」と入力して同じコマンドを実行しても構いません。
   - ファイルを開いていない状態で実行すると、サンプルの `three-way-sync/main.py` が作られます。
3. いつも「左: Python / 中央: Go / 右: Java」の順に並びます。起点はその言語の列に置かれます。
4. 起点を `Ctrl+S` で保存すると（または `Ctrl+Alt+Y`）、残り2言語が生成されます。
   - まだ連動していないファイルで `Ctrl+Alt+Y` を押すと、3分割と変換を一度に行います。
5. どれかの画面でカーソルを動かすと、対応する行が他の2画面でも光ります。マウスを載せると解説が出ます。

### 生成されるファイルの置き場所

元のプロジェクトに他の言語のファイルが混ざらないよう、フォルダ直下の `three-way-sync/` の中に、元と同じフォルダ構成で作ります。

| 起点 | 生成されるファイル |
| --- | --- |
| `src/app/user.py` | `three-way-sync/src/app/user.go` と `user.java` |
| `svc/user.go` | `three-way-sync/svc/user.py` と `user.java` |
| `Main.java` | `three-way-sync/Main.py` と `Main.go` |

- 同じフォルダに `app.py` と `app.go` があり両方を起点にした場合は、重ならないよう `app_from_go.py` のように名前を分けます。
- 複数のファイルを、それぞれ別々に連動させられます。VS Code を開き直しても、連動は引き継がれます。

### 起点のファイルは上書きされません

自分で書いたファイル（起点）は、この拡張機能が書き換えることはありません。
生成された側のファイルを編集・保存しても、起点や他のファイルは変わりません。
生成された側のファイルで3分割を始めようとすると、元の起点ファイルとの連動を開き直します。

## 使うAIを選ぶ

画面右下のステータスバーにある「3言語同期: …」をクリックすると切り替えられます。

| 選択肢 | 内容 |
| --- | --- |
| モック | APIを呼ばず、固定のサンプルを返します。無料。動作確認用。 |
| GitHub Copilot | 書いたコードを実際に変換します。APIキー不要。Copilot の契約と利用枠を使います。 |
| Anthropic (Claude) | 書いたコードを実際に変換します。ご自身のAPIキーが必要。 |
| OpenAI | 同上。ご自身のAPIキーが必要。 |

- Copilot を選ぶと、使うモデルも選べます（「自動」でも可）。初めて変換するとき、VS Code が「Copilot の利用を許可しますか？」と確認するので「許可」を選んでください。
- Copilot を使うには、Copilot の拡張機能が入っていて GitHub にサインインしている必要があります。
- Anthropic / OpenAI の APIキーは各自で用意してください。キーは設定ファイルではなく、OSの資格情報保管庫に保存されます。
- 本物のAIを選ぶと、変換のたびに API 料金や Copilot の利用枠を消費します。保存時の自動変換を止めるには、設定 `threeWaySync.convertOnSave` をオフにします。

## 知っておくとよい点

- 生成後にどれかのファイルを手で編集すると、行の対応がずれるためハイライトは止まります。もう一度変換すると戻ります。
- VS Code を再起動した直後もハイライトは出ません。起点のファイルを一度保存してください。
